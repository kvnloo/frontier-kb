# Measure the learning loop; do not romanticize effort

## Idea (atomic)

The biomarkers of this vault are retrieval hit-rate, synapse weight, idle-days, prune rate, and cycle adherence. Time-on-page and "I studied" are vanity metrics. Nightly jobs must publish the numbers.

## Why it matters for our harnesses

Agents already emit `events`. Humans need the same closed loop. If a note is never retrieved and never fired, it is a candidate for prune regardless of how prestigious the source looks.
