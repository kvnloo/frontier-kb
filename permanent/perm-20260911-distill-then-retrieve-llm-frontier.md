# Teach the LLM frontier by distilling invariants, then retrieving them

## Idea (atomic)

The LLM teaching track is a small set of invariants (post-training-in-harness, tool shape, specialist routing, note-ledger vs conversation memory, context triad). Model names are examples. Retrieval cards ask for the invariant, not the press release.

## Why it matters for our harnesses

If humans learn "SWE-2" as a brand, the knowledge dies on the next rename. If they can regenerate "in-harness RL on the agent loop, not a plugin," they can read the next lab blog in ten minutes.
