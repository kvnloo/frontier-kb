# The connectome is a Drosophila lab instrument, not a product brain

## Idea (atomic)

In 2026 a fly lab’s one-day path is Codex/neuPrint → NeuronBridge → existing split-GAL4 → CsChrimson/GtACR1. That **compiler** (genes → wiring → driver → experiment) is the genuine application. Whole-brain LIF is an **optogenetic ranking prior** for a few circuits, not a brain you ship.

## Why it matters for our harnesses

Do not staff a “run MaleCNS as the factory mind” project. If we touch this stack, we treat it like **Codex for cells**: a queryable atlas that ranks the next wet test, analogous to how the vault ranks notes. PER-944/Xenova is a viewer, not an agent.
