# Optimize the fly by mushroom-body, pinout, and substrate — not by beating Qwen

## Idea (atomic)

Useful work on the fly graph is, in order: **(1) correct I/O pinout** (VNC / descending neurons → body, not a choreographed swipe), **(2) calibrated mushroom-body plasticity** with control assays, **(3) event-driven or neuromorphic substrate** so joules approach biology instead of 10⁸× DRAM, **(4) don't simulate neuropils the task does not use**. Global SGD, "more dopamine," and "train it on SWE-bench" are how you destroy the compiled prior.

## Why it matters for our harnesses

Wirehead already has the right *shape* of experiment: frozen graph, optional `--frozen`, `--no-video-reward` control, checkpoint replay, spike hashes. Next scientific inch is **held-out association** (does PAM11 + odor/visual pattern change MBON readout vs control?), not a prettier garden. Eon's open gap is VNC pinout, not more neurons. Distill surviving motifs into algorithms we can run next to Qwen; keep the 166k LIF as an instrument, not as the factory brain.
