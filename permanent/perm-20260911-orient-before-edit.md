# Orient before edit

## Idea (atomic)

A coding pass starts with blast radius: GitNexus `query` → `context` → `impact` if those MCP tools exist; else Serena symbol lookup; else `rg` + read. DeepWiki and packed trees are orientation only. `gitnexus analyze` is a maintainer install step, not an unattended claim, because it rewrites agent instruction files.

## Why it matters for our harnesses

Cursor/Hermes/OMP workers that skip the graph invent a parallel architecture in a new file. Factory `oss-onboard` must not bootstrap GitNexus. SPEC §3 (execution isolation) now says orient on the existing tree before editing.
