# BDNF and metabolic state are learning prerequisites

## Idea (atomic)

A learning OS that ignores movement, sleep, and metabolic state is pretending the brain is a disk. MOVE before ENCODE. Do not ship a cram product.

## Why it matters for our harnesses

This is not a medical protocol. It is a product constraint: humanity-vault's first cycle phase is MOVE. Agents can skip it; humans should not.
