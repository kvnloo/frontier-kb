# Plasticity needs alertness, then rest

## Idea (atomic)

Focused encoding tags synapses; rest and sleep stabilize the change. A 90-minute ultradian bout followed by NSDR/sleep is the default cycle. Infinite scroll after encode is an anti-plasticity UI.

## Why it matters for our harnesses

Agent loops do not need rest. Humans do. The GraphQL `cycle` type exists so the UI can refuse another encode block until a rest phase is acknowledged. That is human-synergy, not a gimmick.
