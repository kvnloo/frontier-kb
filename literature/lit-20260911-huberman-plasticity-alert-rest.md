# Huberman: plasticity needs alertness, then rest

## Claim (one sentence)

Neuroplasticity is a two-step process: focused, alert encoding (neuromodulators tagging synapses), then rest or sleep to consolidate the change.

## Evidence

- Huberman Lab public protocols: ~90-minute ultradian focus bouts; Non-Sleep Deep Rest (NSDR / yoga nidra-like protocols) after learning; sleep as the main consolidation window; morning sunlight as a circadian / alertness primer.
- Neighboring science (not podcast-original): acetylcholine and norepinephrine as attentional tags; sleep-dependent memory consolidation literature.

## Fact vs interpretation

- Fact: Huberman repeatedly states that trying to learn while depleted, and skipping rest after a learning bout, is an inefficient plasticity schedule.
- Interpretation for this vault: the GraphQL cycle machine has phases MOVE → ALERT → ENCODE → RETRIEVE → REST. The UI should *gate* a rest prompt after an encode block, not offer infinite scroll.
