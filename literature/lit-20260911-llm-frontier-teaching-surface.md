# LLM frontier teaching surface (2026): post-training, harness, memory

## Claim (one sentence)

The cutting edge humans need to learn about LLMs in 2026 is not "bigger chatbots" — it is post-training in the harness, tool/scaffold shape, memory vs note-ledger, and specialist routing.

## Evidence

- SWE-2 is in-harness RL, not a plugin. [[literature/lit-20260910-swe-2-pareto-rl]] · [[permanent/perm-20260910-swe-2-is-a-posttrained-model]]
- Edit-tool ABI moves 27B scores by ~20 points. [[permanent/perm-20260910-scaffold-tool-shape-dominates]]
- Small models are workers or specialists, not orchestrators by default. [[permanent/perm-20260910-small-models-are-workers-or-specialists]]
- Postgres is the operational note ledger; conversation memory is an overlay. [[permanent/perm-20260910-postgres-is-the-operational-kb]]
- Context triad: clear → compact → memory. [[literature/context-triad]]

## Fact vs interpretation

- Fact: those claims are already in this vault with sources.
- Interpretation: humanity-vault's LLM track should teach *those* atoms with encode/retrieve, not a timeline of model names. Model cards rot; harness invariants compound.
