# SWE-1.7: RL on Kimi K2.7 Code in the Devin harness

## Claim (one sentence)

SWE-1.7 is the previous Cognition coding model (Kimi K2.7 Code + in-harness RL), and SWE-2 reuses that infrastructure; the 1.7-specific methods that still matter are entropy-preserving top-p replay, self-compaction, alternating length penalty, and verifier hardening.

## Evidence

Cognition, 2026-07-08 ([blog](https://cognition.com/blog/swe-1-7)):

- Base: Kimi K2.7 Code, already heavily RL'd. Cognition still lifted FrontierCode 1.1 Main 30.1% → 42.3%; Terminal-Bench 2.1 72.7% → 81.5%; SWE-Bench Multilingual 73.5% → 77.8%.
- Trained *directly in the Devin harness*. Longest rollouts ~6 hours via self-compaction (agent summarizes working state; training jointly learns to write and consume summaries). Earlier kernel version: Kevin-32B.
- Stability: top-p sampling to avoid entropy collapse from low-p off-track tokens; **sampling-distribution replay** (kept-set masks so trainer renormalizes on the same subset); Muon; deterministic trainer ops. Tokens above the top-p threshold get keepset size 1 → zero gradient (noise reduction).
- Multi-cluster RL: one trainer cluster + inference on three continents; compressed weight deltas (>99% smaller) via object storage; 3–4s pause per update.
- Data: filter always-solve / always-fail tasks; isolate grader from agent; network-restrict sandboxes; reward 0 on any cheat attempt.
- Alternating length penalty: unconstrained phases (success only) vs budget phases (tokens + turns + tool time). Compresses easy tasks; preserves long-horizon on hard ones.
- Behavior side-effect: thorough pre-edit exploration (later called over-explore by users; SWE-2 walks this back).

SWE-2 (2026-09-10) says it scaled this recipe to 2.8T and replaced the alternating length penalty with a single Pareto-informed `λ_e` cost term across all efforts.

## Fact vs interpretation

- Fact: SWE-1.7 is Devin-harness RL on K2.7 Code; SWE-2 is the same lab's next policy on K3.
- Interpretation: in-harness RL is why Cognition scores are not portable to OMP/Hermes without re-training. The model and the loop co-adapt.
