## Fact vs interpretation

**FACT:** OpenTofu for TF-class free OSS; Pulumi Neo not fully OSS; Intent experimental not TF drop-in.

**CONTEXT:** CDKTF archived 2025-12-10 — don't pick.

**PRINCIPLE:** Works-first: IaC the working path; don't block shipping.

## Semantic IaC layer (later spike candidates)

**Smelt** (https://github.com/lexicone42/smelt) — Declarative IaC with semantic intent/constraint metadata for AI reasoning. Rust-based with content-addressable state (BLAKE3), blast-radius analysis (`smelt explain`), and structured JSON output for agent consumption. **CUE** (https://cuelang.org · https://github.com/cue-lang/cue) — constraint-based config language that can generate Terraform/K8s config, enforcing schemas and policies at a higher abstraction layer. **Mantis** (https://github.com/augur-ai/mantis) — AI-first IaC (OpenTofu fork) powered by CUE; compiles CUE configurations into TF-compatible JSON, combining Terraform and Helm workflows with task-centric state management. Related via CUE/IaC, not Smelt. **Stance:** OpenTofu remains the default Terraform-class foundation for works-first delivery. Smelt = later spike candidate only — evaluate semantic reasoning layers after core IaC workflow validates. Don't block shipping on experimental semantic abstractions.
