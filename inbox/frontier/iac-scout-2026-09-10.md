## Semantic IaC layer (later spike candidates)

**Smelt** (https://github.com/lexicone42/smelt) is an AI-native IaC tool designed for semantic reasoning with declarative configuration carrying intent, ownership, and constraint metadata. Rust-based with content-addressable state (BLAKE3), blast-radius analysis (`smelt explain`), and structured JSON output for agent consumption. Related: **CUE** (https://cuelang.org/) is a constraint-based data validation language that can generate Terraform/K8s config, enforcing schemas and policies at a higher abstraction layer. **Mantis** (https://github.com/augur-ai/mantis) is an OpenTofu fork that compiles CUE configurations into TF-compatible JSON, combining Terraform and Helm workflows with task-centric state management and AI-first generation/validation. **Stance:** OpenTofu remains the default Terraform-class foundation for works-first delivery. Smelt/CUE/Mantis are later spike candidates only — evaluate semantic reasoning layers after core IaC workflow validates. Don't block shipping on experimental semantic abstractions.
